# 画个锤子 · Lux3D 验证台

轻量静态验证原型，手机、平板和电脑共用；Pointer Events 画板，无 Apple 专属适配。无构建依赖。

## 当前边界

**未接通 Lux3D 自动生成，也没有 AI 鉴定。** 当前环境无 API key，技能引用的生产运行文件不可读取。网站不会用演出样例冒充生成。真实质量实验采用“平台生成 → 导出 GLB → 网站录入”的人工管线。等待测试独立运行，支持预生成模型揭晓或明确标注的表情样例。

## 手机上怎么测

1. 创作：选主体，复制固定英文提示词；或用画板画草图并保存 PNG。
2. 在已登录的 Lux3D 官方平台做真实生成，下载 GLB，记实测秒数、实扣积分、任务 ID。不要将 API 密钥输入本站。
3. 回本站录入：极速文生每主体三次，共 30 次，失败也录入。图生：剑、锤子、离谱物三张草图各两次；标准版精修单独记录。
4. 盲评：三人依次选 A/B/C，独立回答两项；前台隐藏主体、提示词、参考图。随机样本编号。两人同时认可两项则该模型可用。失败直接计不通过。完整主实验 ≥18/30 为 Go。重复主体额外记录不替换预先约定的前三次。
5. 等待：填非队员代号，交替测试普通与锻造、20/30/40 秒；答感受、记录中途退出及主动复玩。切后台记录无效；不把等待样例计入质量。真实模型揭晓也属于预生成素材，不是本次实时生成。
6. 结果：导出 JSON 完整备份（含模型、草图、评分），CSV 留作报告。跨设备用备份导入合并。无云端多人同步，浏览器清缓存会丢数据。

等待假设没有预设量化通过线，网站只报告行为证据。AI 属性/模型形状影响战斗/战斗爽感不在本次验证范围。

## 开发

`python3 -m http.server 8000 --directory dist` 后访问 localhost:8000。

`node --check dist/app.js` 检查语法。model-viewer 4.1.0 已本地附带（上游 Apache-2.0），不依赖 CDN。项目为 throwaway 快速验证原型。无账户、无服务器、无密钥存储。

## 接通自动生成的后续条件

需要可用的官方 API 文档/插件运行文件和服务器侧区域密钥。应部署服务器代理，执行余额/报价确认、提交并持久化 task ID、轮询状态、下载真实模型、记录成本与耗时。不得把供应商密钥放入静态 JS，也不得猜测接口。当前没有实现或声称该流程已经跑通。
