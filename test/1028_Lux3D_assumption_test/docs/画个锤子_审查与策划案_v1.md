# 「画个锤子」（暂名）参赛审查 + 拿奖导向策划案 v1

> 群核科技 Aholo 全球 3D AI 黑客松 · 2026-10-27 · 截止提交 2026-11-19 19:00
> 方向：玩家用文字描述或手绘草图"画"出武器 → Lux3D 生成 3D 模型 → AI 鉴定属性 → 拿着去互殴/闯关。单机先行，联网对战后置。
> 团队已拍板：优先做本方向，中国式高考暂缓。
> 本文档只做审查与设计策划，不含整体执行排期。

---

## 第一部分：合格性审查

### 总结论：**合格，且拿奖天花板高于高考方向——但成败押在两个未验证假设上，48 小时内必须跑 demo 回答**

| 审查维度 | 结论 | 依据 |
|---|---|---|
| 品类空白 | ✅ 成立 | "文字/草图 → AI 生成 3D 武器 → 属性鉴定 → 打架"交叉位无人占据；最近占位者 Voodoo《Draw Joust!》只是 2D 超休闲、无 AI 生成、无属性抽卡 |
| 技术栈契合（30%） | ✅ 最强契合 | Lux3D 不是工具而是**玩法循环本身**——"生成即玩法"是对"承担核心作用"的满分回答，优于高考方向的任何嵌入设计 |
| 趣味与传播（25%+5%） | ✅ 已验证公式 | Suck Up! 零营销一个月 YouTube 破千万：AI 实时生成 × 搞笑 × 强传播是短视频爆款公式；"离谱生成结果"本身就是传播素材 |
| 生成即抽卡的情绪 | ✅ 有百年先例 | Monster Rancher（1997，读盘生成怪物）证明玩家对随机生成结果接受度极高——只要包装成"收集/揭晓"而非"敷衍" |
| 生成质量 | ⚠️ **未验证** | 队长原话"最大问题就是产出不保证"；但"Lux3D 是工业建模出身，静态武器可能做得更好"的猜想合理——武器/道具恰在其材质甜区，待 demo 证实 |
| 生成延迟 | ⚠️ 可设计化解 | 极速版约 20 秒、标准版约 5 分钟——"秒级即时"不可行，"20–40 秒演出化等待"可行（Monster Rancher 神殿召唤仪式、Tripo Clash 论文已验证此模式） |
| 战斗手感 | ⚠️ 团队短板 | 0 代码团队做打击感是真实风险；但最小体量可控（见第二部分第 4 节） |
| 合规/舆情 | ✅ 低风险 | 唯一雷区是"AI slop"观感——Steam 研究显示被动 AI 内容遭差评；**规避法：AI 生成必须是玩家主动抽奖（机制），不是美术偷懒（内容）**。本作天然符合 |

### 两个关键假设（Go / No-Go，今天下午的 demo 就是为此）

1. **Lux3D 生成武器/道具类静态模型，"能认出是什么 + 能拿去打架"的可用率是否够高**（队长猜想吃工业建模红利，待验证）。
2. **20–40 秒的生成等待，能否被"锻造/召唤演出 + AI 鉴定台词"消化成抽卡揭晓感**，而不是卡顿感。

### 必须吸取的前车之鉴

- **Spore 陷阱**：编辑器极强、玩法极浅，"一英里宽一英寸深"。本作生死线是——**生成的模型形状必须真实影响战斗属性**（AI 鉴定不是贴皮，要有可解释的视觉→属性映射），否则就是噱头。
- **AI slop 陷阱**：生成结果必须好笑/好看/离谱得有节目效果；鉴定台词和武器命名是笑点主产地，值得专门投入。

## 第二部分：拿奖导向策划案

### 1. 奖项策略（团队拍板：三单项主攻）

| 目标 | 奖项 | 契合逻辑 |
|---|---|---|
| 主攻 ① | **游戏应用奖（5000）** | 品类完全对口，"生成即玩法"在游戏赛道里技术栈叙事最硬 |
| 主攻 ② | **怪点子奖（5000，创意单项）** | "画个锤子拿去打"本身就是怪点子——玩家创造×AI鉴定×互殴的组合前所未有 |
| 主攻 ③ | **最没有用奖（5000，创意单项）** | 离谱武器图鉴="没有用"美学的极致：抽到马桶搋子还非得拿它赢。荒诞感是设计与传播的双重资产 |
| 顺手叠加 | 国内人气奖（5000） | 离谱武器截图天然是小红书/抖音素材 |
| 保持冲击 | 二等/一等奖 | 若 demo 完成度与视频出圈超预期，总分仍有一战之力，但不为其牺牲单项奖的怪味纯度 |

**注意**：三个单项若能兼得就是 1.5 万，超过三等奖——但**奖项能否兼得官网未披露，必须在赛事社群书面确认**，这直接决定主攻组合是否成立。

**对设计的回灌**：主攻怪点子奖和最没有用奖意味着"离谱"要从副作用升级为**设计目标**——鉴定属性的"离谱度"维度、图鉴里专门设"最没有用武器"陈列位、Demo 视频往荒诞方向剪。评委评这两个奖时找的就是这个味。

### 2. 作品定位

- **暂名**：《画个锤子》——双关、好记、自带搞笑预期，与画风自洽。
- **一句话**：你说/画什么，就生成什么、鉴定什么、拿它打什么——一个 AI 武器鉴定乱斗游戏。
- **三重爽点**：抽卡的期待感（生成）→ 鉴定的笑点（AI 吐槽）→ 验证的爽感（我这把到底行不行）。
- **画风哲学**：核心创意不被固定画风绑定——这反而是本作最大优势。**生成物风格不一不再是缺陷而是设定**（"万物皆可武器"）：场景和角色用统一搞笑卡通打底，武器保留生成原生质感，每把都独一无二。这直接化解了 Lux3D 质量一致性的难题。

### 3. 核心循环（技术栈 30% 的满分逻辑）

```
描述/画（文生+图生双入口）
  → Lux3D 生成（极速版 20 秒：锻造/召唤演出 + AI 鉴定台词滚动）
  → AI 鉴定（命名 + 属性 + 吐槽，视觉特征→属性的可解释映射）
  → 装备上场
  → 战斗验证
  → 入图鉴（收集欲驱动复玩， Monster Rancher 验证）
```

关键设计决策：

- **AI 鉴定是灵魂**：多模态模型读取生成结果，按可解释规则出属性——长度→攻击范围、锋利度→伤害、材质→重量/速度、离谱度→特殊效果。鉴定词和命名要足够好笑（笑点主产地，对标画风）。
- **延迟即演出**：生成期间播锻造/召唤动画 + 鉴定台词逐行滚动，把 20 秒做成抽卡揭晓仪式；标准版 5 分钟包装成高价值操作"精锻"。预生成池兜底（生成失败/超时从池抽，不打断心流）。
- **双输入入口**：文字描述（文生，稳定保底）+ 手绘草图/拍照（图生，参与感最强，"我画的"拥有感是分享动机来源）。

### 4. 战斗设计（趣味 25%，单机 demo 先行）

- **最小体量**：1 个竞技场 + 1 套挥砍/受击/击飞动作 + 打击感五件套（命中停顿 4–8 帧、屏幕震动、击退、命中粒子/白闪、每动作配音效）——game jam 社区验证过的最低爽感配方。
- **武器实现**：团队只需做"手部挂载点 + 攻击判定框"，武器模型全部由 Lux3D 生成，动画量可控在个位数。
- **对战路径**：demo 期 PVE（木桩/AI 假人）→ 参赛版可做**异步影子对战**（上传自己的武器数据，打别人的影子）——成本远低于真联网，但给评委"对战感"；真联网大乱斗明确放赛后路线。
- **爽点验证逻辑**：战斗的深层功能是"鉴定结果的验证场"——打得爽不爽其次，"我这把离谱武器到底行不行"的好奇心才是驱动循环的燃料。

### 5. 传播设计

- Demo 视频钩子（前 30 秒）："我画了根辣条 → 20 秒生成 → AI 鉴定'SSR·辣条之怒' → 一刀砍翻全场"。
- 小红书/抖音素材单元：离谱武器图鉴截图、鉴定台词截图、对战反转时刻，带 `#Aholo黑客松`。
- 玩家侧传播：每张武器截图都是"我创造的"——拥有感驱动自发分享，比高考方向的截图传播动机更强。

### 6. 验证标准

- **假设 1（质量）**：10 个武器 prompt × 3 次生成，三人盲评"能认出是什么 + 能上场"率 ≥ 60% 为通过。
- **假设 2（等待体验）**：做一个 20 秒等待演出原型，非队员看完不觉得"卡"，觉得"在抽奖"。
- **玩法假设**：打击感五件套灰盒 + 3 把生成武器，非队员玩 5 分钟后想"再打一把/再抽一把"。
- 判断证据以非队员行为为准（主动要求复玩），礼貌称赞不算。

### 7. 未决项

1. 引擎：战斗手感需求 → Unity/UE 对比（队友 three.js 经验利于 Web 传播，但打击感调校 Unity 生态更稳）——按 demo 整合结果定
2. AI 鉴定的模型选型与提示词工程（多模态 API 额度与成本）
3. 积分预算：每把武器一次生成，测试 + 试玩的消耗速率推算
4. 异步影子对战是否进入参赛版范围（看单机 demo 完成度）
5. 与高考方向的关系：暂缓但保留——两方向共享 Lux3D 管线能力，若本方向假设 1 验证失败，高考方向的信物系统仍是回退选项
